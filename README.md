# ⚔️ Classe de Herói

Desafio desenvolvido em **JavaScript** utilizando orientação a objetos para representar diferentes tipos de heróis e seus ataques.

## 🚀 Tecnologia utilizada

- JavaScript

## ✨ Funcionamento

O projeto possui uma classe `Heroi` com nome, idade e tipo. O método de ataque escolhe uma ação diferente conforme o tipo do herói, como mago, guerreiro, monge ou ninja.

## 🧠 Conceitos praticados

- Classes e objetos
- Construtores
- Métodos
- Propriedades
- Estrutura `switch`
- Template strings

## ▶️ Como executar

Com o Node.js instalado, execute:

```bash
node index.js
```

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar conceitos introdutórios de orientação a objetos e estruturas de decisão em JavaScript.
